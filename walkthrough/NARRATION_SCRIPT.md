# Walkthrough narration script

Use this if you want to re-record with **your own voice** (often preferred for candidate submissions).

**Suggested length:** ~2–3 minutes  
**Prototype:** https://avantika-27.github.io/GreenGrowth-AI-Powered-Tax-Platform/

## How to record yourself (QuickTime)

1. Open the live site in Chrome (full screen).
2. macOS: **QuickTime Player → File → New Screen Recording** (also enable microphone).
3. Follow the click path below while reading the script.
4. Export and upload (Drive, Loom, or unlisted YouTube) and link it in the README.

## Click path

1. Land on Dashboard (Sam / preparer)
2. Open Maya’s return → click **Taxable interest** and **Business gross receipts**
3. Go to **AI insights** → open a recommendation → Accept / Inspect in return
4. **Messages** → send an **Internal note**
5. Jump via related links to a **Document**
6. **Documents** → search `W-2`
7. Switch user to **Maya Chen** → complete first-run → **Home** → **Return status**
8. As Maya, open **Messages** (internal note hidden)
9. Switch to **Priya Nair** (reviewer dashboard)

## Spoken script

Hi, I’m walking through GreenGrowth — a greenfield prototype of an AI-powered tax platform for clients and CPAs.

On the firm dashboard, I optimized for one question: what should I work on right now? Actions are ranked by urgency and due date, not vanity metrics.

In return review, every number is traceable — field, source document, page, extracted value, and any transformation. The same affordance system shows what’s AI-generated, verified, editable, needs approval, or locked.

AI insights show what the model did, why, the evidence, the uncertainty, and the one suggested action. Raw JSON is optional so transparency doesn’t become noise.

Collaboration is contextual: threads attach to documents and issues, show who owns the next step, and keep internal notes out of the client view.

Navigation preserves context with breadcrumbs and related links across returns, documents, messages, and tasks.

Documents scale with search and progressive disclosure — hundreds of items without dumping everything at once.

For a first-time client like Maya, the first screen answers what to do next in seconds. Status uses shared phases with plain language for clients and ownership detail for staff.

Roles share one product shell — preparer, reviewer, admin, seasonal, taxpayer, business owner — instead of six separate apps.

What’s simulated: OCR, the AI model, auth, and messaging backends. What’s real: the interaction design, prioritization, correction flows, and permissions you can click through.

That’s the prototype — designed for trust, clarity, and time-to-action across all ten challenges.
